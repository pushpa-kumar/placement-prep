### Maximum Sum of Two Numbers Without Shared Digits — from array a, pick indices i≠j such that a[i] and a[j] share no base-10 digits, maximizing a[i]+a[j] (or return -1 if impossible).
- Company: DRW
- Role: Software Engineer (Intern)
- Type: OA
- Round/Stage: Codility OA, 3 problems in 150 minutes
- Status: REAL
- Source: PracHub — https://prachub.com/interview-questions/solve-three-algorithmic-oa-problems
- Answer/Discussion: Reduce each number to a 10-bit "digit mask"; two numbers are compatible iff mask1 & mask2 == 0; keep max value per mask (1,024 possible masks) — O(n log A + 1024²), or O(n log A + 10·2^10) via sum-over-subsets DP.

### Min-Difference with Minimal Swaps — given two equal-length digit strings S and T (length up to 100,000, digits only, no leading zeros), you may swap S[i] with T[i] at chosen indices; among all swap sets that minimize |int(S) − int(T)|, return the minimum number of swaps needed. Example: S="29162", T="10524" → answer 2.
- Company: DRW
- Role: Software Engineer
- Type: OA
- Round/Stage: Online Assessment (Codility-style)
- Status: REAL
- Source: PracHub — https://prachub.com/interview-questions/solve-three-algorithmic-oa-tasks and https://prachub.com/coding-questions/solve-odd-string-digit-swap-patient-slot-assignment ; also LinkJob.ai — https://www.linkjob.ai/interview-questions/drw-codility-assessment/
- Answer/Discussion: Greedy approach — scan left to right, tentatively swap digits, compute how the difference changes at each position, and execute swaps that reduce the overall difference.

### Two-Choice Slot Assignment ("patient scheduling") — given arrays A and B of length N (each patient has two preferred slots, 1..S) determine whether every patient can be assigned to A[k] or B[k] such that no slot is used by more than one patient.
- Company: DRW
- Role: Software Engineer
- Type: OA
- Round/Stage: Online Assessment (Codility-style)
- Status: REAL
- Source: PracHub — https://prachub.com/interview-questions/solve-three-algorithmic-oa-tasks and https://prachub.com/coding-questions/solve-odd-string-digit-swap-patient-slot-assignment ; also LinkJob.ai — https://www.linkjob.ai/interview-questions/drw-codility-assessment/
- Answer/Discussion: Model each patient as an undirected edge between two slot-nodes; build the bipartite/slot graph and check each connected component has at most as many patients (edges) as distinct slots (nodes) involved — a pseudoforest condition, verifiable via union-find. LinkJob's account frames it as bipartite matching solvable via the Hungarian algorithm, O(N × S).
